# Posh-CEF 
Version 1.0
Creates a properly formatted CEF message (UTF-8 encoded string) that can be written to file with Out-File (encodes UTF-8 by default)
or sent via SYSLOG using the Posh-SYSLOG module (https://github.com/poshsecurity/Posh-SYSLOG)

This supercedes the old version which was only published on psgallery (as posh-cef) but not github. I lost access to my microsoft.com email
when I left the company which was used to publish posh-cef (v 0.9.0) to PSGallery, so this will be the new active one.

This project is now MIT licensed and managed via github.
